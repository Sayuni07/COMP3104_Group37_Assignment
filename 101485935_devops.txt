COMP 2156 is a DevOps course that introduces students to tools and practices used in modern software development. Topics include Git, GitHub, version control, branching, collaboration, continuous integration, and continuous delivery. These practices help development teams automate workflows, identify problems earlier, and deliver reliable software more efficiently.

Git enables developers to track changes and collaborate on shared projects. GitHub hosts repositories and supports pull requests, code reviews, and team collaboration. CI workflows can automatically run checks when changes are pushed, helping teams identify issues before merging code.

A branching strategy allows developers to work independently without changing the main branch directly. Pull requests provide a way for team members to review changes before merging them. Clear commit messages make project history easier to understand and maintain.
